# general

Free training notes, course links, slide decks, scripts and reference material on Microsoft 365 and the Microsoft Cloud from Robert Crane (CIAOPS).

This is where I keep the supporting material for my presentations, courses and study sessions. It's for MSPs and IT pros working with Microsoft 365, security, Copilot and the wider Microsoft Cloud. Everything here is free to use. Most folders hold PDFs of slides and handouts, plus plain-text reference files full of links I've found useful.
