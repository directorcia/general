## Methodology

| Parameter | Method | Caveat |
|---|---|---|
| File size | SharePoint file metadata | Exact byte count from library metadata. |
| Characters | Extracted document text character count | Excludes some Word binary/formatting data. |
| Word count | Token count from extracted text after removing markup | May differ from Microsoft Word's built-in count. |
| Total pages | Estimated from word count / 500 | Exact Word pagination depends on page setup, fonts, margins, images, and renderer. |
| Sections/headings | Lines beginning with # in the extracted Markdown representation | Reflects extracted heading structure, not necessarily Word style names. |
| Image markers | Extracted image placeholders found in text | Some images may be represented outside plain text. |
